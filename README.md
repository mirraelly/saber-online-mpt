# FinAcademy

Landing page desenvolvida como atividade prática do curso **Mais Pra TI**, utilizando **HTML**, **CSS** e **JavaScript**.

## Funcionalidades

- Landing page responsiva
- Botão de chamada para ação
- Formulário de contato
- Consumo da API ViaCEP para preenchimento automático do endereço
- Interações com JavaScript

## Tecnologias

- HTML5
- CSS3
- JavaScript
- API ViaCEP
